# app-ui/new/ — LP showcase copies

These are marketing-owned **showcase copies** of parent-app screens, embedded
as iframes in the LP's "what the app looks like" section. They exist so the
marketing site can show the app without depending on the engineering repo.

They are **not** the engineering source of truth for the parent app — don't
treat changes here as shipping to the real product. If the real app UI
changes, these need a manual re-sync.
